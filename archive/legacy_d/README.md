# Legacy D Prototypes

This directory preserves three standalone D simulations that were previously kept under `z_disabled/`:

- `crypto_auth_sim.d` – modular authentication and synchronization demo built around Fermat validation and CRT timing.
- `mini_rocket_sim.d` – thermal/entropy control mock-up for a MEMS "mini-rocket" experiment.
- `primal_logic.d` – quick processing pipeline for experimenting with "Primal Logic" transforms on scalar time series.

They are not part of the Heart–Brain Coupling Model build or documentation, but remain available for reference. None of the
files are compiled by default; integrate them manually if you need to revisit the original experiments.
