# Cardiac Subsystem

Use this package to model cardiac electrophysiology and hemodynamics. Suggested contents include:

- Low-order oscillatory heart models for rapid experimentation.
- Detailed cell-level or tissue-level simulators if higher fidelity is required.
- Interfaces for generating ECG, pressure, and volume waveforms consumed by downstream analytics.

Keep coupling-ready state variables accessible so the neural subsystem can modulate them.
